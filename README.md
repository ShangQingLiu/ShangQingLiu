# Shang-Ching (Sam) Liu

Robotics PhD student and Research Associate in the [TAMS group](https://tams.informatik.uni-hamburg.de/people/liusq/) at Universität Hamburg. I work on vision-language-action models, bimanual manipulation, 3D affordance understanding, and safety-aware robot behavior planning.

## Current work

- **[EBiM](https://ebim-benchmark.github.io/)** — Embodied Bimanual Manipulation Benchmark and Challenge 2026 (organizer). Code lives in the [EBiM-Benchmark](https://github.com/EBiM-Benchmark) organization, including [`benchmark`](https://github.com/EBiM-Benchmark/benchmark).
- Safety-aware robotic behavior planning with an explicit constraint space ([arXiv:2611.18026](https://arxiv.org/abs/2611.18026)).
- Low-cost mobile bimanual manipulation ([arXiv:2611.15381](https://arxiv.org/abs/2611.15381)).
- PAVLM: point-cloud affordance understanding with vision-language models ([arXiv:2410.11564](https://arxiv.org/abs/2410.11564), IROS 2025).
- Collaboration on [FoxBrain](https://github.com/TranNhiem/FoxBrain_LLMs) (Hon Hai Research Institute).

## Selected code

- [jarvix_qa](https://github.com/ShangQingLiu/jarvix_qa) — JarviX, an LLM no-code platform for tabular data analysis (EMNLP 2023 Industry Track).
- [PBBM-robot-librarian](https://github.com/ShangQingLiu/PBBM-robot-librarian) — multi-stage book perception and bimanual shelf rearrangement (IAS-18).
- [CLIIP](https://github.com/ShangQingLiu/CLIIP) — individual SARS-CoV-2 infection probability from interaction data (Scientific Reports, 2021).
- [CMU-VLA-Challenge](https://github.com/ShangQingLiu/CMU-VLA-Challenge) — TAMSxGalbot submission to the 2025 IROS CMU VLA Challenge.
